# Make QRcode CLI C++

Đây là chương trình nhỏ bằng C++ dùng thư viện [qrcodegen](https://github.com/nayuki/QR-Code-generator) của tác giả [Nayuki](https://github.com/nayuki) build qrcode từ nội dung nhập vào ra terminal hoặc ghi vào file text 

## Cách cài đặt 
```bash
git clone https://github.com/trgchinhh/qrcodecli-cpp.git
cd qrcodecli-cpp/
g++ run.cpp -o run.exe
./run.exe
```
> Chỉ cần build và chạy file run, nó sẽ tự động biên dịch và chạy mã nguồn, sau khi chạy run sẽ sinh ra thư mục bin/main.exe nằm cùng chổ với file run. Lần tới chạy chỉ cần chạy trong bin/main.exe không cần chạy run để biên dịch lại
